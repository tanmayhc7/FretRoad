# Name shortlist

Chosen: **Fretroad** (decided 2026-10-29). A web search found no existing product with this name. GitHub, domain and trademark availability are still to be checked by hand.
"Wayfinder" was the earlier working title; it is generic, and the fretboard-trainer space is crowded with "Fret___" names.

Ideas (none have been checked for GitHub, domain, or trademark availability):

| Name | Why |
|---|---|
| Fretroad | Fretboard plus the road story. Short, easy to say. A quick search found no obvious guitar product with this name. |
| Neckroads | The neck as a set of roads. Slightly more distinctive. |
| Lowtide | The first town. Memorable, but says nothing about guitar. |
| Harbor Light | The third stop; warm and calm. Needs a guitar word added. |
| Marlow | The mentor's name. Personal and brandable. |
| Capo & Compass | Playful; hints at navigation. A little long. |
| Roadsong | Road plus music. Likely crowded. |

Before choosing: search GitHub, the App Store, and a domain registrar for the top two or three.
